# Enterprise IT Automation and Operations
## Overview
This repository contains technical projects inspired by real-world enterprise IT operations, troubleshooting, systems administration, automation, and compliance activities.

Projects are based on lessons learned while supporting Windows systems, patch management, system health validation, operational workflows, and technical investigations. All documentation has been generalized and does not contain proprietary, confidential, or customer-specific information.

## Skills Demonstrated
- Windows Administration
- PowerShell Automation
- Troubleshooting
- Root Cause Analysis
- Patch Management
- Documentation
- System Health Monitoring
- Compliance Validation
- Operational Process Improvement

## Current Projects
### Windows Update Remediation Tool
PowerShell-based remediation workflow for Windows Update failures caused by corrupted update components and patch deployment issues.

### Windows Health Status Audit Tool
PowerShell-based health assessment tool that evaluates Windows Update status, BITS status, storage utilization, patch recency, internet connectivity, and reboot requirements.

### Splash Screen / Shell Investigation
Troubleshooting case involving scheduled task behavior, shell initialization issues, privilege escalation limitations, and administrative account troubleshooting.

### STIG Compliance Audit (In Progress)
PowerShell-based compliance validation project focused on Windows servicing-level requirements, security baselines, and automated compliance checks.
